# E-commerce Analytics Project

## 📌 Project Overview

This project focuses on analyzing e-commerce sales and order data to identify key business trends, customer behavior, product performance, and sales insights.

The project involves data cleaning, analysis, KPI calculations, and dashboard creation to transform raw e-commerce data into meaningful business insights.

## 🛠️ Tools & Technologies

* Microsoft Excel
* SQL
* Data Analysis
* Data Visualization
* Interactive Dashboards

## 📊 Key Analysis

* Total sales and order analysis
* Customer performance analysis
* Product and category analysis
* Sales and return analysis
* Monthly and yearly trends
* KPI tracking
* Data cleaning and validation
* Interactive dashboard development

## 🎯 Project Objective

The objective of this project is to analyze e-commerce data and create interactive dashboards that provide clear insights into sales performance, customers, products, and returns.

## 📁 Project Files

This repository contains the datasets, analysis files, and dashboard created as part of the E-commerce Analytics project.
